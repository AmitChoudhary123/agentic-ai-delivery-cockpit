# Demo

This demo ranks agentic AI opportunities using a practical delivery lens: value, feasibility, risk, owner, and control pattern.

Run:

```bash
python demo/run_demo.py
```

Expected behavior:

- Produces a sorted portfolio of agentic AI use cases
- Separates `scale`, `pilot`, and `defer` candidates
- Flags higher-risk workflows for human approval

Why it matters: enterprise agentic AI is a delivery and operating-model problem, not only a framework problem.
